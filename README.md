# Автоматический ИИ-обработчик заявок на клееный брус

Проект автоматизирует обработку входящих писем от клиентов с помощью локальной LLM и n8n.

## Архитектура и логика работы
1. **Email Trigger (IMAP):** Бот прослушивает почтовый ящик.
2. **Очистка текста (Code):** Из письма удаляются HTML-теги, остается чистый текст.
3. **Аналитик (LM Studio):** Первая нода нейросети читает текст и пишет текстовый анализ (какие детали найдены, что нужно перевести в мм, чего не хватает).
4. **Форматировщик (LM Studio):** Вторая нода берет анализ и с помощью строгой **JSON Schema** упаковывает данные в структурированный JSON.
5. **Генерация HTML (Code):** Скрипт собирает из JSON красивую таблицу для письма.
6. **Send Email (SMTP):** Ответ отправляется клиенту.

## Инструкция по развертыванию

### 1. Настройка нейросети (LM Studio)
1. Скачайте и установите [LM Studio](https://lmstudio.ai/).
2. Найдите и скачайте модель `google/gemma-4-e2b`.
3. Перейдите на вкладку **Developer** (Local Server), выберите модель и нажмите **Start Server** (порт `1234`).
4. **Важно:** Включите опцию **Serve on Local Network** в настройках сервера, чтобы Docker-контейнер с n8n мог до него достучаться.

### 2. Запуск инфраструктуры (Docker)
1. Клонируйте этот репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/ИМЯ_РЕПОЗИТОРИЯ.git
   cd ИМЯ_РЕПОЗИТОРИЯ

2. Создайте файл .env в корне проекта и добавьте секретный токен для связи n8n и Python-раннера:

N8N_RUNNERS_AUTH_TOKEN=ваш_придуманный_пароль_123

3. Запустите контейнеры в фоновом режиме:

bash:
docker compose up -d

n8n будет доступен по адресу: http://localhost:5678

### 3. Импорт Workflow и настройка Credentials
В интерфейсе n8n создайте новый Workflow и выберите Import from File, указав файл workflow.json из этого репозитория.

Настройте учетные данные (Credentials):

LM Studio API: Host URL: http://host.docker.internal:1234, API Key: оставить пустым.

IMAP (Входящие): Ваш логин, пароль приложения, сервер imap.yandex.ru (порт 993, SSL).

SMTP (Исходящие): Ваш логин, пароль приложения, сервер smtp.yandex.ru (порт 465, SSL).

Критически важно: В узле Send an Email в поле From Email должен быть указан ровно тот же адрес, который вы используете для авторизации в SMTP-креденшеле. Иначе Яндекс заблокирует отправку.

Сохраните воркфлоу и включите тумблер Publish (в правом верхнем углу).
